Weather Application

Project Description:

This is a Python GUI-based Weather Application developed as part of the Oasis Infobyte Python Programming Internship. The application allows users to search for weather information of any city. It displays the current weather conditions along with a 5-day forecast and hourly forecast using the OpenWeatherMap API. Users can also switch the temperature display from Celsius to Fahrenheit through the graphical interface.

Features:

- GUI built using Tkinter
- Search weather by city name
- Displays current temperature
- Shows humidity
- Displays weather condition
- Shows wind speed
- Weather icon based on current conditions
- 5-Day Weather Forecast
- Hourly Weather Forecast
- Temperature conversion from Celsius to Fahrenheit
- User-friendly interface with input validation
- Error messages for invalid city names or empty input

 Technologies Used:

- Python
- Tkinter
- Requests
- Pillow (PIL)
- OpenWeatherMap API

Files Included:

- `gui.py` – Graphical User Interface
- `weather_app.py` – Weather API logic and helper functions
- `README.md` – Project documentation

How to Run:

1. Install Python 3.x

2. Install the required libraries:

```bash
pip install requests pillow
```

3. Add your OpenWeatherMap API key in `weather_app.py`.

4. Run the program:

```bash
python gui.py

```
Output:
The application provides:

- City name input
- Current weather details
- Weather icon
- Temperature
- Humidity
- Weather condition
- Wind speed
- Temperature unit conversion (°C to °F)
- 5-Day Weather Forecast
- Hourly Weather Forecast
