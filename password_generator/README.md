Random Password Generator 
  
Project Description :

This is a Python GUI-based Random Password Generator developed as part of the Oasis Infobyte Python Programming Internship.
The application allows users to generate strong and secure passwords based on their selected criteria. It provides options to include uppercase letters, lowercase letters, numbers, and symbols. The generated password can be copied to the clipboard, and password strength is displayed based on its length.

Features :

- GUI built using Tkinter
- User-defined password length
- Uppercase, Lowercase, Numbers, and Symbols selection
- Minimum 8-character password validation
- At least 2 character types must be selected
- Password strength indicator (Weak / Medium / Strong)
- Copy Password to Clipboard
- Option to exclude ambiguous characters (0, O, 1, l)
- Password history saved in file
- View password history
- Input validation with error messages

Technologies Used:

- Python
- Tkinter
- Secrets Module
- String Module
- Pyperclip
